# S05 — Bill on the 31st: window by scheduleDate, action by dueDate

Pins `../../02-business-rules/01-calendar-and-scheduling.md` §2.1: the bill
that was too late for January's window and too early for February's, and
vanished from every forecast.

## Setup

- Calendar `FI`. Today = `2026-01-10`.
- Plan item `Rent` — expense `€900.00`, monthly, `paymentDay: 31`,
  `dayType: next-work-day`, recurring.
- 2026-01-31 is a **Saturday**; 2026-02-01 a Sunday; 2026-02-02 a Monday and
  a working day in FI.

## Expected

Occurrence for January:

- `scheduleDate` = **2026-01-31** (day 31 exists in January, no clamp).
- `dueDate` = workingDayAdjust(2026-01-31, next-work-day, FI)
  = **2026-02-02**.
- Generated by a `[2026-01-01, 2026-01-31]` scan: **yes** — membership is
  decided by `scheduleDate` at both ends.
- Generated by a `[2026-02-01, 2026-02-28]` scan: **no** — it belongs to
  January only. February's own occurrence is `scheduleDate` 2026-02-28
  (clamped), `dueDate` 2026-02-27? — no: 2026-02-28 is a Saturday, so
  `next-work-day` → **2026-03-02** (Monday). Membership: February.
- Exactly one occurrence per month across any tiling of scans (A4): scanning
  Jan and Feb separately or `[2026-01-01, 2026-02-28]` at once yields the
  same two occurrences with the same deterministic ids.

Ordering (§2.2): the generated list is sorted by `dueDate`, so January's
occurrence (due 02-02) still precedes February's (due 03-02).

Materialisation gating:

- `occurrence.materializeDue({ asOf: 2026-01-31 })` posts **nothing** —
  dueDate 2026-02-02 > asOf. Action gates on `dueDate`.
- `occurrence.materializeDue({ asOf: 2026-02-02 })` posts January's €900.00,
  transaction dated per the materialiser rule, occurrence `settled`.

Month-end clamping series for `paymentDay: 31` (leap-aware; 2028 is a leap
year): Jan 31, Feb 28 (2026), Mar 31, Apr 30 … and Feb **29** in 2028.

## Failure this pins

Comparing the *adjusted* date at the window's upper bound: 2026-02-02 >
2026-01-31 excluded it from January while 2026-01-31 < 2026-02-01 excluded it
from February — the occurrence belonged to neither window and every forecast
from that month on silently dropped the rent.
